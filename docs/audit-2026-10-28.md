## 已修复

| 范围 | 问题与修复 | 回归覆盖 |
| --- | --- | --- |
| CLI | `readFile(0)` 无法读取 stdin；改用输入流读取 UTF-8 任务和学习正文 | `client.test.mjs` |
| MCP | Content-Length 按字符切片会截断中文并破坏后续帧；改用字节缓冲，处理分片、EOF、非法请求和输入上限 | `mcp.test.mjs` |
| MCP/client | 长任务阻塞同连接的 status/kill；改为并发处理并等待已接收请求完成。HTTP 长轮询预留传输时间，断流统一转为 ConnectError | `mcp.test.mjs`、`client.test.mjs` |
| 引擎入口 | npm 全局软链不符合原入口匹配；先 realpath 再识别 dsh 的 JavaScript 入口 | `unit.test.mjs` |
| 事件与用量 | JSON null 导致宿主异常；超长行可能只丢弃一部分；多步 token 误取最大值。现在容忍非对象事件、整行丢弃超限输出、按步累加并保留 reasoningTokens | `engine.test.mjs`、`unit.test.mjs` |
| 进程终止 | POSIX 直接子进程先退出时跳过升级，残留后代；现在仍向进程组发 SIGKILL。Windows 改为先 taskkill /T /F | `process-tree.test.mjs` |
| 台账 | 保存 API 截断后的任务和结果；写入尚未完成时读取可能漏记录。现在保存全文，读取等待已入队写入，学习写入失败向调用方报告 | `engine.test.mjs`、`store.test.mjs` |
| HTTP | 非法 wait/tail 在启动任务后才报错；超限请求可能断连；多余路径仍执行操作；live 筛选在分页之后。现在先校验、返回可读 413、精确匹配路径、先筛选后分页 | `routes.test.mjs` |
| Loopback | IPv4-mapped IPv6 的 Host 被误拒；Origin 只比较主机。现在接受回环映射地址并核对协议，拒绝带用户信息或路径的 Host | `loopback.test.mjs` |
| 市场 | 过滤异常条目后 raw 记录错位；原始 format-1 的版本 source 未生成 install；缓存无容量限制。现在保留对应 raw，生成 npm/固定 Git 安装参数，缓存最多 16 个索引并处理断流 | `market.test.mjs` |
| 实验室路径 | scaffold force 可沿已有软链越界；main 可读取目录外文件；profile 别名可能绕过当前宿主限制。现在校验真实路径，备份配置只接受普通文件 | `lab.test.mjs` |
| 实验室恢复 | 原备份不存在、后来新增的配置不会删除；不完整备份可能部分恢复。现在预检备份并还原四类配置文件的存在状态，返回 removed | `lab.test.mjs` |
| 实验室验证 | dump-config 成功即宣称成功，嵌套或禁用 id 也被计入。现在支持预期 name，返回 missing 和 verificationScope；改写操作串行，boot 等待临时宿主关闭 | `lab.test.mjs` |

## 第二轮补查

按用户要求跳过真实模型调用。用户已确认 Qoder 侧单向接入可用；本轮只读对照独立 `codex-dsh-connect` 与本机 dsh 的启动契约，保留原生 CLI、argv、stdin 和 JSON 事件的接法，未改动参考项目。

- 修复实验室只在配置检查和备份时使用 `lab.dshHome`、实际子进程却继承其他 `DSH_HOME` 的问题；安装、配置和 boot 命令统一传入已授权目录。
- MCP 在执行前校验工具 schema，拒绝缺少必填字段、错误类型/枚举/数组项与未知参数，避免非法调用触发副作用；异常工具名和空结果也返回合法协议响应。
- 非对象客户端配置回退为空配置，修复 JSON null 导致的崩溃。
- 空白 `sessionId` 在启动前返回 400，避免意外创建新会话。
- 主题读取和导出先筛选再限制数量；损坏、非对象或数组台账行不再占用有效记录数量。
- 实验室正确报告不可读或目录类型的 main，检查完整 stderr 中的激活失败，拒绝读取符号链接操作日志，并补测串行队列错误恢复。
- 新增启动契约测试：包含中文、换行、命令样式文本的任务原样走 stdin，argv、cwd 和宿主环境传递符合预期。本轮新增 13 项测试，全部包含在 85 项完整测试中。

## 验证边界与待办

- 完整测试使用假 dsh 和本地索引，按用户要求跳过真实模型 smoke；未执行真实 Desktop 宿主 E2E。

- Windows 终止逻辑已调整，但未在真实 Windows 执行；新增 macOS CI 配置在扫描阶段未运行，上传后的结果以 GitHub Actions 为准。
- 实验室配置存在、host 可达不能证明插件运行时激活；验证特定插件应显式提供 name。未传 name 时只从最近 500 条操作推断，无法推断时仅验证 profile 配置。
- 实验室路径检查防已有符号链接绕过，不构成抵御并发外部文件替换的文件系统沙箱。子代理仍继承宿主凭据与权限，见 security.md。
